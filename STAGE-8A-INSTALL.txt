99's Guide — Stage 8A Remaining Supabase Read Audit
====================================================

PURPOSE
-------
Find exactly which remaining Supabase/PostgreSQL tables and API routes are still
read by the backend before moving any more runtime reads to Cloudflare D1.

READ-ONLY:
- no Supabase writes
- no D1 writes
- no R2 changes
- no deploy
- no source-code changes

RUN FROM PROJECT ROOT
---------------------
node audit-stage8a-remaining-supabase.mjs

The script creates:
- stage8a-audit-report.txt
- stage8a-audit-report.json

It inspects:
- server.ts
- prisma/schema.prisma
- cloudflare-content-api/src/index.ts (if present)
- PostgreSQL row counts/table sizes via SELECT only, if DATABASE_URL is available

EXPECTED END
------------
No database was modified.
No source file was modified.
STAGE 8A AUDIT SCRIPT COMPLETED

STOP THERE.
Upload stage8a-audit-report.txt to ChatGPT.
