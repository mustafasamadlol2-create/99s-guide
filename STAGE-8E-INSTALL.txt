STEP 1 — REPLACE ONLY THE PRIVATE WORKER SOURCE
-----------------------------------------------
Copy:

cloudflare-private-data-api\src\index.ts
cloudflare-private-data-api\wrangler.jsonc

into the existing cloudflare-private-data-api folder.

Do NOT touch:
cloudflare-content-api

STEP 2 — DEPLOY PRIVATE WORKER
------------------------------
From project root:

cd cloudflare-private-data-api

npx wrangler deploy -c wrangler.jsonc

cd ..

The existing PRIVATE_DATA_SYNC_SECRET stays attached to this Worker.

STEP 3 — CONFIRM THE WRITE MIRROR IS STILL CLEAN
------------------------------------------------
From project root:

node verify-stage8d2b-outbox.mjs

If the outbox is not clean, STOP. Do not run the shadow parity verifier yet.

STEP 4 — SET THE PRIVATE SECRET LOCALLY

Do NOT send the value to ChatGPT.

The Worker URL has a default, but you can also set:
