Prompt 17 implementation is provisionally approved.

Two closure requirements remain insufficiently proven:

1. The mandatory regression commands requested by Prompt 17 were not individually reported in the final report.

2. The report states:
   - `app_text_scale` is applied as an inline `fontSize` on the application shell.
   - Reading Size uses explicit reading typography whose base values include `rem`.

This requires a precise composition audit.

CSS `rem` resolves against the document root font size, not an arbitrary ancestor font size.

Therefore, if `app_text_scale` is applied only to a non-root App shell while Prompt 17 reading typography uses explicit `rem` values, Reading Size may bypass or partially bypass the existing device-local text scale.

DO NOT ASSUME this defect exists.

Inspect the actual source and computed architecture first.

Prompt 17B exists to:

A. prove the two systems compose correctly,
or
B. repair only that composition if it is actually broken,

and then run the missing mandatory regression matrix.

Do NOT redesign Motion.
Do NOT redesign Reading.
Do NOT begin Home Subject Order.
Do NOT modify `.agents/*`.
