# 1. USER-REPORTED FAILURES

The feature currently has reliability problems across AI MCQ and Flashcard workflows.

Observed failures include:

- An uploaded source containing approximately 80 MCQs can take longer than two minutes and terminate with an AI provider error.
- Some PDFs extract correctly while another valid PDF returns zero items.
- Some PDFs are not read completely.
- Larger source documents may lose questions near the end.
- A single malformed provider response can lose the entire operation.
- Extract can be slow.
- Generate can be slow or incomplete.
- Enhance can be slow or incomplete.
- Generate/Enhance can exhibit the same provider/structured-output failures as Extract.
- Large structured outputs increase truncation and malformed JSON probability.
- A PDF/image may contain valid MCQs or Flashcards but the system may report zero candidates.
- Scanned/image-only PDFs must remain supported.
- Temporary provider/network failures must not destroy a long operation.

This Prompt must solve the SYSTEMIC issue rather than only increasing one timeout.
