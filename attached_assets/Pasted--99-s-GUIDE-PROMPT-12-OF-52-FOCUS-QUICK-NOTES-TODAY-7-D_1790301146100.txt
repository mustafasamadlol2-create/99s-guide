# 99’s GUIDE — PROMPT 12 OF 52

## FOCUS QUICK NOTES

## TODAY / 7-DAY / MONTH FOCUS METRICS

## POST-FOCUS ACTION CONTEXT

### PRIVATE CANONICAL NOTES — NO UI — NEVER SCHEDULE

Prompts 1–11 and Prompt 9R have been completed and approved.

Prompt 12 implements the final backend/runtime foundation for the first Focus phase:

1. durable private Quick Notes linked to a canonical Focus Session and Lecture;
2. deterministic Focus statistics from existing `StudyDailyMetric`;
3. reusable post-Focus action context;
4. optional conversion of a Quick Note into a future Focus Plan item;
5. absolutely no Calendar/Schedule integration.

This prompt does NOT build the Focus UI.

---

# 1. FROZEN PRODUCT RULES

Quick Notes are private Focus content.

A Quick Note:

```text
belongs to one authenticated user
belongs to one Focus Session
inherits that Session's Lecture
may remain as a private note
may later become a Focus revisit/queue item
```

It must NEVER become:

```text
CalendarEvent
Academic Schedule event
personal planner event
```

There is no student personal planner.

---

# 2. QUICK NOTE PRIVACY

Quick Note content is:

```text
PRIVATE_STUDY
```

It must NOT be copied to:

* D1 Focus projections;
* Analytics Engine;
* StudyEvent payloads;
* owner aggregate analytics;
* public profile;
* leaderboard;
* logs.

Canonical storage only:

```text
PostgreSQL
```

Do not create a Cloudflare Quick Note mirror.

Creating, editing, archiving, or converting a note must NOT automatically produce a `StudyEvent`.

* effort;
