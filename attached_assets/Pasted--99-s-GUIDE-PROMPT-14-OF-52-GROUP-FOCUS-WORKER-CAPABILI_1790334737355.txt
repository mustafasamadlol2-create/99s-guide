# 11. TOKEN FORMAT

Use a compact signed token with standard JWT/JWS semantics.

Preferred:

```text

```

* Node backend supports it;

If the repository already contains a proven Node + Worker compatible signing library such as `jose`, reuse it.

Otherwise implement the minimum strict compact HMAC signing/verification required here using built-in crypto/Web Crypto.

Do NOT introduce a large auth dependency unnecessarily.
