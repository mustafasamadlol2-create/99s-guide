# 17. ROOM CLOSED RECONCILIATION

If canonical PostgreSQL says:

```text
Room.status = CLOSED
```

the DO must:

1. normalize current timer state;
2. close all active participation intervals at server time;
3. set realtime phase to `CLOSED`;
4. persist terminal state;
5. broadcast `ROOM_CLOSED`;
6. close sockets;
7. create/freeze terminal summary;
8. begin canonical summary delivery if not already reconciled.

Do not continue realtime timer after canonical closure is known.

Do not delete historical participation accumulator.
