# 23. RULE ACTIVATION

Internal service conceptually:

```ts
activateGamificationRuleSet(version)
```

In one transaction:

1. load DRAFT target;
2. validate complete definition bundle;
3. compute checksum;
4. verify persisted checksum;
5. lock Gamification rule-set lifecycle;
6. RETIRE previous ACTIVE rule set if one exists;
7. mark target ACTIVE;
8. set `effectiveFrom`;
9. commit.
