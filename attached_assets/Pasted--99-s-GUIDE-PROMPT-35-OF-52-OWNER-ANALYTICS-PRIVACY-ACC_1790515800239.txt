# 99’s GUIDE — PROMPT 35 OF 52
## OWNER ANALYTICS PRIVACY + ACCESS CONTROL
## SMALL-COHORT SUPPRESSION + ANTI-INFERENCE RULES
## SAFE AGGREGATE API EXPOSURE
### OWNER-ONLY BY DEFAULT — NO INDIVIDUAL STUDENT ANALYTICS — NO AI — NO UI

Prompts 1–34 have been completed.

Prompt 34 established:

```text
canonical PostgreSQL academic/study facts
→ deterministic aggregate queries
→ lecture / subject / cohort aggregate DTOs
→ owner-academic-analytics-v1
```

Prompt 34 deliberately did **not** expose those analytics through HTTP because privacy and access-control semantics had not yet been frozen.

Prompt 35 now adds that safety boundary.

Frozen roadmap:

```text
Prompt 35 — Owner privacy / access
Prompt 36 — deterministic Analyzer DTO / metrics
Prompt 37 — AI Study Insight cache / Workers AI
Prompt 38 — Ask My Study Data
Prompt 39 — local-first audio / ambient
```

Do NOT implement Prompt 36+ early.

---

# 1. PRIMARY OBJECTIVE

Safely expose Prompt 34 deterministic aggregate analytics to the authorized owner while preventing:

1. individual-student analytics;
2. small-sample disclosure;
3. accidental student identification;
4. behavioral disclosure from tiny groups;
5. sensitive Mastery/Retention leakage;
6. differencing through arbitrary windows;
7. custom subgroup probing;
8. raw evidence access;
9. analytics-based student ranking;
10. insecure shared caching.

Prompt 35 must implement:

```text
authorization
+
privacy transformation
+
small-sample suppression
+
fixed safe query windows
+
bounded owner APIs
+
privacy-safe logging
```

---

# 24. PRIVACY DISCLOSURE TYPE

Implement a reusable typed wrapper conceptually:

```ts
type AnalyticsDisclosure<T> =
  | {
      status: "VISIBLE";
      value: T;
      contributingUsers: number;
    }
  | {
      status: "NO_DATA";
      value: T;
      contributingUsers: 0;
    }
  | {
      status: "SUPPRESSED";
      value: null;
      contributingUsers: null;
      reason:
        | "LOW_SAMPLE"
        | "LOW_INTERACTION_COUNT"
        | "DISTRIBUTION_PRIVACY";
    }
  | {
      status: "UNAVAILABLE";
      value: null;
      contributingUsers: null;
      reason: "SOURCE_UNAVAILABLE";
    };
```

Adapt exact types to repository conventions.
