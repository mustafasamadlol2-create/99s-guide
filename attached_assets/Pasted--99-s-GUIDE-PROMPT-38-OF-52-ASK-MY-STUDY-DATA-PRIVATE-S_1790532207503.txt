# 1. PRIMARY OBJECTIVE

Implement a private **Ask My Study Data** service that allows the authenticated student to ask bounded natural-language questions about their own canonical study data.

Examples:

```text
"Which lectures need review?"
"How has my MCQ accuracy changed recently?"
"Am I studying more consistently?"
"Which subject have I focused on most?"
"Do I have repeated MCQ mistakes?"
"What does my Focus data show?"
"When do I usually study?"
"Which lectures are overdue for review?"
"How many active study days did I have this month?"
```

The architecture must:

1. accept one bounded user question;
2. classify the question into a safe supported intent;
3. retrieve deterministic facts only from approved Prompt 36 / Prompt 33 / Prompt 32 services;
4. build a minimal intent-specific grounding payload;
5. call Cloudflare Workers AI only where natural-language explanation is useful;
6. validate the AI answer against retrieved facts;
7. reject unsupported/private-dangerous requests;
8. prevent arbitrary database querying;
9. prevent cross-user access;
10. avoid raw study-history dumping;
11. avoid canonical writes;
12. remain useful when AI is unavailable.
