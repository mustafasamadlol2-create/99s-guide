# 39. AUDIO STATE MACHINE

```text

```

---

# 40. `IDLE`

No source loaded.

---

# 41. `LOADING`

Source selected and being prepared.

---

# 42. `READY`

Source loaded and can play.

---

# 43. `PLAYING`

---

# 44. `PAUSED`

User intentionally paused.

---

# 45. `INTERRUPTED`

Playback stopped because of lifecycle/system interruption, not explicit user pause.

---

# 46. `ERROR`

Current source cannot play.
