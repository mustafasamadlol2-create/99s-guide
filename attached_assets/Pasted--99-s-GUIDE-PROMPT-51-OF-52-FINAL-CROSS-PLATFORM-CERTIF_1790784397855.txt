# 3. HONEST EXECUTION STATUS

Every certification item must be classified as one of:

```text
PASS
FAIL
NOT_RUN
BLOCKED
NOT_APPLICABLE
```

Definitions:

```text
PASS
=
actually executed and passed

FAIL
=
executed and failed

NOT_RUN
=
environment did not permit execution

BLOCKED
=
execution should have been possible but an unresolved dependency/defect prevented it

NOT_APPLICABLE
=
not supported / intentionally outside product contract
```

Never convert `NOT_RUN` into `PASS`.
