# 99’s GUIDE — PROMPT 8 VERIFICATION GATE

## REAL POSTGRESQL OUTBOX + TRANSACTION + IDEMPOTENCY VALIDATION

### THIS IS A VERIFICATION GATE ONLY — IT DOES NOT CHANGE THE 52-PROMPT ROADMAP

Prompt 8 implemented the Study Event ingestion foundation successfully, but one architecture gate remains unresolved:

> The `StudyDailyMetric` D1 projection enqueue path assumes the provisioned `PrivateD1SyncOutbox` schema and its `id`/revision behavior are compatible with the new transaction-bound raw SQL insert.

The current tests prove the logic with mocks, but they do NOT prove the real PostgreSQL contract.

Prompt 9 must NOT begin until this is verified.

---

Verify against a **safe non-production PostgreSQL database** that:

```text

+

+
```

can actually execute in one PostgreSQL transaction using the repository's real Prisma/raw-SQL implementation.


is suitable as the monotonic projection revision currently assumed by Prompt 8.

This gate is about verification first.

Do not implement new product behavior.
