  * `src/features/lectures/components/CreateAnki.tsx`
  * `POST /api/flashcards`
* Admin authorization is already handled by `requireAdmin`
* Current file uploads are orchestrated by the Node backend
* Production Lecture PDFs are stored in R2
* Temporary AI source files must NOT automatically become `Material` rows
* No current MCQ/Flashcard bulk creation route exists
* No current MCQ/Flashcard duplicate detection exists
* No existing AI system exists
* No current Zod-based validation architecture exists

Do not re-audit the entire project.

Inspect files as needed while implementing, but Phase 1 is accepted.
