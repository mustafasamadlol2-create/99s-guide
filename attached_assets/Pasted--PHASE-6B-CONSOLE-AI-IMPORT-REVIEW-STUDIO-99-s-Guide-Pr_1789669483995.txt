
# 1. PRIMARY GOAL

Inside the existing MCQ and Anki/Flashcard Console workflows, provide two creation paths:

```text
Manual
AI Import
```

The existing manual workflows must remain unchanged.

```text
Choose operation
→ Choose source method
→ Configure operation
→ Submit
→ See processing state
→ Receive candidates
→ Review candidates
→ Edit candidates locally
→ Select/reject candidates
→ inspect warnings/source evidence
```

But:

**DO NOT WRITE ANY CANDIDATE TO THE DATABASE IN PHASE 6B.**
