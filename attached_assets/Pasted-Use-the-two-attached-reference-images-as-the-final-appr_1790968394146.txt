# 6. Audio artwork behavior

Implement dynamic artwork for locally selected audio files.

### Required behavior

When no audio file is selected:

- display the existing/default mountain artwork shown in the reference.

When an audio file is selected:

- inspect the file for embedded artwork/cover metadata;
- if valid embedded cover artwork exists, display that artwork inside the Focus Audio card;
- if the file has no embedded artwork, continue showing the default mountain artwork.

Conceptually:

```text
selected audio
    ↓
embedded artwork exists?
    ↓
YES → display embedded artwork
NO  → display default mountain artwork
```

This must work locally.

Do NOT upload artwork or the audio file to the backend merely to display it.

Do not persist unnecessary binary/base64 data.

Reuse the existing local-first Focus Audio architecture.

If an object URL is created for artwork, properly revoke it when replaced/unmounted.

Handle unsupported or corrupt metadata gracefully.

Failure to read artwork must never prevent the audio file itself from being used.

The fallback must always be the default mountain artwork.
